Privacy Policy

Health MCP · last updated 8 September 2026

What this application is

Health MCP is a personal, single-user tool. Its only user is its owner. It reads the owner's own health and fitness data from the Google Health API after the owner grants access through Google's standard OAuth consent screen.

What data is accessed

Only the data covered by the scopes shown on the consent screen: activity and fitness, sleep, health metrics and measurements, nutrition, profile and settings. Access is read-only for the purpose of personal tracking.

Where the data goes

Nowhere. The application runs locally on the owner's own computer. Health data and OAuth tokens are stored only in the owner's local user account on that machine. No health data is transmitted to this website, to any server operated by the developer, or to any third party. There is no analytics, no advertising, and no tracking of any kind.

Sharing and selling

Data is never sold, rented, shared, or transferred to anyone. It is not used to train models and it is not used for advertising.

Retention and deletion

Data and tokens live only in local files and are deleted when the owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions, which immediately stops any further access.

This website

This site is a set of static pages hosted on GitHub Pages. It contains no forms, no accounts, no cookies set by the site, and it collects nothing. GitHub may log requests as part of operating its hosting service.
